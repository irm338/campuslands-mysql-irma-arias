# Módulo de Datos - Carreras Urbanas (Ejercicio 010 - Avanzado)

Solución desarrollada en **MySQL** enfocada en el uso profesional de funciones de agregación (`COUNT` y `SUM`) para análisis de indicadores deportivos y financieros de eventos de atletismo urbano.

## Estructura de la Solución
- **ddl/schema.sql**: Creación de la base de datos y tabla optimizada con restricciones numéricas.
- **dml/inserts.sql**: Inserción de 8 registros de atletas con datos de categorías, distancias, tiempos y pagos.
- **dql/consultas.sql**: 5 consultas analíticas aplicando agrupamientos, sumatorias y conteos estratégicos.

## Instrucciones de Ejecución
Ejecuta los scripts en tu gestor MySQL en orden estricto:
1. Ejecutar `ddl/schema.sql`
2. Ejecutar `dml/inserts.sql`
3. Ejecutar `dql/consultas.sql`
