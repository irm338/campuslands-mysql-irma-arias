# Módulo de Datos - Fútbol Sala (Ejercicio 008 - Avanzado)

Solución desarrollada en **MySQL** enfocada en la gestión avanzada de esquemas, actualizaciones con `UPDATE` y consultas analíticas.

## Estructura de la Solución
- **ddl/schema.sql**: Creación de la base de datos y tabla optimizada con restricciones.
- **dml/inserts.sql**: Inserción de registros y transacciones de actualización de estados y puntajes.
- **dql/consultas.sql**: 5 consultas analíticas con ordenamientos, filtros y funciones de agregación.

## Instrucciones de Ejecución
1. Ejecutar `ddl/schema.sql`
2. Ejecutar `dml/inserts.sql`
3. Ejecutar `dql/consultas.sql`
