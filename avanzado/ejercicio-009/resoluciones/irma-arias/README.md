# Módulo de Datos - Kickboxing (Ejercicio 009 - Avanzado)

Solución desarrollada en **MySQL** enfocada en la práctica profesional de eliminación controlada de registros mediante la instrucción **DELETE**, respaldada con restricciones y consultas analíticas.

## Estructura de la Solución
- **ddl/schema.sql**: Creación de la base de datos `db_kickboxing_avanzado` y la tabla `luchadores_kickboxing` con validaciones.
- **dml/inserts.sql**: Inserción de 8 registros de atletas y ejecución de operaciones `DELETE` controladas por estado y código.
- **dql/consultas.sql**: 5 consultas analíticas aplicando ordenamientos, agrupamientos y funciones de agregación.

## Instrucciones de Ejecución
Ejecuta los scripts en tu gestor MySQL en orden estricto:
1. Ejecutar `ddl/schema.sql`
2. Ejecutar `dml/inserts.sql`
3. Ejecutar `dql/consultas.sql`
